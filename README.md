# 數學・物理 學習總入口 · Math & Physics Hub

由 Google Sites「數學・物理 學習總入口」重建，部署於 GitHub Pages。

Rebuilt from the Google Sites hub for secondary maths and physics learning tools, hosted on GitHub Pages.

## 結構 / Structure

- **首頁** (`index.html` / `數學物理總入口.html`) → 數學科、物理科兩大入口
- **數學科** (`數學科.html`) → 指數定律、因式分解、展開（練習工具稍後嵌入）
- **物理科** (`物理科.html`) → 單位、公式、計數機技巧、概念詞彙（練習工具稍後嵌入）

Homepage → Maths / Physics subject pages → tool cards. Practice HTML tools will be embedded in a later step.

## 本機預覽 / Local preview

用瀏覽器開啟 `index.html`，或於本目錄啟動靜態伺服器即可。

Open `index.html` in a browser, or serve this folder with any static file server.
